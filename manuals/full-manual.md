### 1. Introducción
CUBERBOX Nexus Core es una plataforma de comunicaciones omnicanal de alto rendimiento diseñada para centros de contacto modernos. Este manual detalla el funcionamiento de cada módulo y su integración dentro del ecosistema.

### 2. CENTRO DE OPERACIONES (Operación Diaria)

![Operaciones en Tiempo Real](https://images.unsplash.com/photo-1521791136064-7986c2923216?auto=format&fit=crop&w=1200&q=80)

#### 2.1 Dashboard
- **Uso**: Vista general del estado del sistema, llamadas activas, agentes logueados y SLAs.
- **Administrador**: Configura los widgets y umbrales de alerta.
- **Usuario**: Visualiza su desempeño personal y el estado general de su campaña.

#### 2.2 Terminal Agente (Smartphone Interface)
- **Uso**: Interfaz principal del agente para recibir/realizar llamadas y gestionar chats.
- **Integración**: Conectado directamente al motor SIP y al CRM para mostrar fichas de cliente.

#### 2.3 Monitor GTR & GTR Avanzado
- **Uso**: Supervisión en tiempo real de la operación. Permite ver estados de agentes, tiempos de espera y colas.
- **Administrador**: Puede realizar acciones de supervisión (escucha, susurro, intrusión).

#### 2.4 Monitor Burbujas (Live Monitor)
- **Uso**: Visualización gráfica de canales activos y flujos de llamadas en curso.

#### 2.5 Omnicanal Hub (WhatsApp/Social)
- **Uso**: Gestión centralizada de mensajes de WhatsApp, Facebook, TikTok e Instagram.
- **Integración**: Utiliza APIs oficiales de Meta y otros proveedores.

### 9. GUÍA DE INTEGRACIONES TÉCNICAS

![Integraciones de Ecosistema](https://images.unsplash.com/photo-1518770660439-4636190af475?auto=format&fit=crop&w=1200&q=80)

#### 9.1 Inteligencia Artificial (Gemini API)
![Integración con Gemini AI](https://images.unsplash.com/photo-1677442136019-21780ecad995?auto=format&fit=crop&w=1200&q=80)
CUBERBOX Nexus Core utiliza modelos de lenguaje avanzados para automatizar la atención.
- **Pasos de Configuración**:
  1. Obtenga una API Key desde Google AI Studio.
  2. En CUBERBOX Nexus Core, vaya a **AI Studio > Configuración**.
  3. Ingrese la API Key y seleccione el modelo (ej: `gemini-1.5-flash`).
  4. Defina el "System Instruction" para guiar el comportamiento de la IA.
  5. Vincule el modelo a un flujo de IVR o Campaña de Broadcast.

#### 9.2 Omnicanalidad (Meta Business API)
![Integración con Meta Business](https://images.unsplash.com/photo-1611746872915-64382b5c76da?auto=format&fit=crop&w=1200&q=80)
Integración con WhatsApp, Facebook Messenger e Instagram.
- **Pasos de Configuración**:
  1. Cree una aplicación en el portal de Meta for Developers.
  2. Configure el Webhook de CUBERBOX Nexus Core en la consola de Meta (URL: `https://tu-dominio/api/whatsapp/webhook`).
  3. Obtenga el "Access Token" de larga duración y el "Phone Number ID".
  4. En CUBERBOX Nexus Core, vaya a **Omnicanal Hub > Canales** y registre las credenciales.
  5. Configure las plantillas de mensaje (Templates) para notificaciones salientes.

#### 9.3 FreeSwitch & Telefonía (SIP/ESL)
El motor de medios que gestiona el audio y la señalización.
- **Pasos de Configuración**:
  1. **Trunks SIP**: En **SIP Telephony**, agregue su proveedor (IP, puerto, credenciales).
  2. **Dialplan**: Configure las reglas de entrada y salida para enrutar llamadas a colas o IVRs.
  3. **ESL (Event Socket Layer)**: Asegúrese de que el puerto 8021 esté abierto para que el conector de CUBERBOX Nexus Core pueda controlar FreeSwitch.
  4. **Codecs**: Priorice G711 (PCMU/PCMA) o OPUS para mejor calidad.

#### 9.4 Keycloak (Autenticación Centralizada)
![Seguridad con Keycloak](https://images.unsplash.com/photo-1555066931-4365d14bab8c?auto=format&fit=crop&w=1200&q=80)
Gestión de identidad y Single Sign-On (SSO).
- **Pasos de Configuración**:
  1. Cree un Realm en Keycloak (ej: `CUBERBOX-Nexus`).
  2. Cree un Client de tipo `openid-connect` con acceso `confidential`.
  3. Configure las "Valid Redirect URIs" apuntando a su instancia de CUBERBOX Nexus.
  4. En CUBERBOX Nexus Core, vaya a **Ajustes Core > Seguridad** e ingrese la URL de Keycloak, Client ID y Secret.
  5. Mapee los roles de Keycloak con los niveles de usuario de CUBERBOX Nexus.

#### 9.5 CRM & ERP (Webhooks & API)
![Integración de Negocios](https://images.unsplash.com/photo-1552664730-d307ca884978?auto=format&fit=crop&w=1200&q=80)
Sincronización de datos de clientes y registros de llamadas.
- **Pasos de Configuración**:
  1. **Push Data**: Configure Webhooks en CUBERBOX Nexus para enviar eventos (ej: `CALL_END`) a su CRM.
  2. **Pull Data**: Use el **CRM Connect** para realizar consultas HTTP durante una llamada (IVR) y personalizar la atención.
  3. **API REST**: Utilice la API documentada de CUBERBOX Nexus Core para que su ERP pueda extraer reportes o insertar contactos en listas de marcación.
  4. **Fichas**: Configure la URL del CRM en el perfil de campaña para que se abra automáticamente en el Terminal del Agente.

### 10. GUÍA DE INSTALACIÓN DETALLADA

![Proceso de Instalación](https://images.unsplash.com/photo-1587620962725-abab7fe55159?auto=format&fit=crop&w=1200&q=80)

#### 10.1 Instalación mediante ISO (Recomendado)
Este método instala Debian 12 y CUBERBOX Nexus Core de forma totalmente automatizada.
- **Pasos**:
  1. **Descarga**: Obtenga la imagen `debian-12-cuberbox-nexus.iso`.
  2. **Medio de Arranque**: Grabe la ISO en un USB (mínimo 8GB) usando Rufus o BalenaEtcher.
  3. **Arranque**: Inicie el servidor desde el USB.
  4. **Selección**: En el menú de arranque, seleccione **"CUBERBOX Nexus Core Automated Install"**.
  5. **Automatización**: El instalador particionará el disco, instalará el sistema base y ejecutará el script de CUBERBOX Nexus Core sin intervención.
  6. **Finalización**: El sistema se reiniciará. Acceda vía web a `https://[IP-SERVIDOR]:3000`.

#### 10.2 Instalación mediante Script (Servidor Existente)
Para servidores que ya tienen Debian 12 (Bookworm) instalado.
- **Pasos**:
  1. **Acceso**: Inicie sesión como `root` vía SSH.
  2. **Descarga**: Ejecute `curl -O https://[TU-DOMINIO]/nexus-installer.sh`.
  3. **Permisos**: Otorgue permisos de ejecución: `chmod +x nexus-installer.sh`.
  4. **Ejecución**: Inicie el asistente: `./nexus-installer.sh`.
  5. **Asistente TUI**:
     - Seleccione el tipo de instalación (**Standalone** o **Cluster**).
     - Ingrese la **Ruta de Instalación** (ej: `/opt/nexus`).
     - Configure el **Dominio/FQDN** para los certificados SSL.
     - Ingrese su **SignalWire PAT Token** y contraseña de Base de Datos.
  6. **Progreso**: Espere a que la barra de progreso llegue al 100%. El script compilará las librerías necesarias y configurará los servicios systemd.

#### 10.3 Verificación Post-Instalación
Independientemente del método, verifique el estado de los servicios críticos:
- `systemctl status nexus-web` (Interfaz y API)
- `systemctl status nexus-core` (Conector Go)
- `systemctl status freeswitch` (Motor de Telefonía)
- `systemctl status postgresql` (Base de Datos)
